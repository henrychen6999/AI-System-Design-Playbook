# AI System Design Playbook

Version: 1.0  
Last Updated: 2026-09-18

這個 Repository 是 AI System Design Playbook 的正式版本。

用途：

- AI 專案開始前的需求與架構檢查
- RAG、Agent、API、MCP、安全與 Evaluation 設計檢查
- 專案進行中的 Review
- 專案完成前的驗收與交接

## AI 使用方式

AI 接手專案時，不要預設讀取全部 Playbook 文件。

第一步只讀：

`PLAYBOOK_INDEX.md`

再依 `PLAYBOOK_INDEX.md` 的 Routing 規則，讀取目前任務需要的模組。

## 正式規則來源

`PLAYBOOK_INDEX.md` 為 Playbook 的主要入口與共用規則。

`01` ～ `08` 為各專業模組。

不要依賴聊天紀錄取代正式 Playbook 文件。
